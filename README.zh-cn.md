# MetroStart

中文 | [English](README.md)

适用于 KDE Plasma 6 的 Windows 10 风格磁贴开始菜单（作为 Plasma 小组件）。

MetroStart 高度还原了 Windows 10 开始菜单：带有分组标题的固定磁贴、附带首字母索引栏与字母网格的“所有应用”列表，以及包含电源与用户菜单的可折叠左侧边栏。它以覆盖在面板上方的全屏浮层形式打开，而非传统的 Plasma 弹出窗口；同时也提供传统（非全屏）的开始菜单模式。

所有与本机相关的配置——包括应用程序、图标、磁贴排列、壁纸和用户头像——均直接读取自 Plasma 或主目录下的布局文件，不会对系统其他部分做任何修改。

已在 **Plasma 6.6** / **Qt 6.10** (Wayland) 环境下测试通过。

## 功能特性

* **两种布局模式** — 支持全屏开始菜单，或可自由拖拽调整宽高的传统菜单。
* **磁贴系统** — 完整支持 Windows 10 磁贴尺寸（磁贴右键菜单支持“小”和“中”，通过布局文件可配置“宽”和“大”）、分组标题，以及单个磁贴与整个分组的拖拽排序。所有调整均会实时保存。
* **应用列表** — 包含带首字母标题的“所有应用”列表、快速跳转字母网格，窗口菜单模式下还提供“最近添加”区域。
* **左侧边栏** — 鼠标悬停时自动展开，集成休眠、关机与重启功能，以及账户管理、锁定和注销选项。
* **右键菜单** — 支持固定到开始屏幕、取消固定、调整大小、重命名分组、打开文件所在位置或以管理员身份运行应用。
* **外观与动效** — 高度贴合 Windows 10 原版体验的开关交叉淡入淡出效果、逐行入场的磁贴动画、跟随指针点亮的悬停边框以及按压波纹反馈。
* **自适应显示** — 在任意屏幕缩放比例下均能保持相对于桌面的协调尺寸，自动填满工作区并止步于面板上方；磁贴列数也会根据屏幕宽度自动调整。
* **实验性功能（默认关闭）** — 提供带有多种配色方案和图标风格的彩色“早期 Windows”磁贴皮肤，以及动态磁贴（时钟、电池、日期、日历、天气、照片）及其内容切换动画。

## 安装

### 通过 Release 文件安装

在 [Release 页面](https://github.com/xiahe173/MetroStart/releases/latest) 下载 `MetroStart-<version>.plasmoid`，然后依次点击 *添加部件 → 从文件安装*，或者在终端中运行以下命令安装：

```bash
kpackagetool6 -t Plasma/Applet -i MetroStart-<version>.plasmoid
```

随后在 *添加部件* 中将 **MetroStart** 添加到面板即可。该小组件驻留在面板上，并在面板上方展开菜单，不会遮挡面板。

### 从源码安装

本小组件采用纯 QML 编写，无需编译：

```bash
cmake -B build
cmake --install build --prefix ~/.local
```

### 卸载

```bash
kpackagetool6 -t Plasma/Applet -r org.kde.plasma.metrostart
```

直接从面板中移除该小组件即可停止使用。

## 设置

*外观* 页面：

* **图标** — 面板按钮的显示图标（默认为 Windows 网格图标）。
* **强调色** — 用于按压状态下的分组标题、拖拽占位符以及侧边栏指示条。
* **开始菜单布局** — 选择全屏或窗口化模式。
* **图标填充比例** — 由于部分图标主题自带内边距，磁贴会在稍大的容器内绘制图标。若图标显得过小可调低此值，若溢出磁贴边界可调高此值。默认值为 85%。
* **实验性选项** — 勾选开启后，可配置磁贴风格与调色板、天气数据源、动态磁贴轮播与动画变体、早期皮肤的图标样式，以及使用应用自身主色作为磁贴背景。当此开关关闭时，上述所有项均保持默认状态，磁贴会忽略布局文件中的颜色与动态磁贴记录，且磁贴右键菜单也会隐藏相关选项。

*语言* 页面：仅控制本小组件的界面语言——可选跟随系统会话、英语 或 简体中文。修改后立即生效，无需重启 `plasmashell` 或更改桌面其他部分的语言。

## 布局文件

磁贴排列数据保存在 `~/.config/metrostart/layout.json` 中，完全由你掌控：单个列可以容纳任意数量的拖入分组，且分组与列本身不绑定固定位置。

```json
{
  "version": 2,
  "columns": [
    {
      "groups": [
        {
          "title": "",
          "tiles": [
            { "app": "org.kde.dolphin.desktop", "size": "2x2" },
            { "app": "org.kde.konsole.desktop", "size": "1x1" },
            { "label": "KiCad", "icon": "kicad",
              "exec": "kicad", "size": "2x2" }
          ]
        }
      ]
    }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `app` | 应用程序的 `.desktop` 文件名；将自动读取其名称与图标。若对应的应用未安装，则会自动跳过该磁贴。 |
| `label`, `icon` | 可选的自定义覆盖项。`icon` 可以是图标主题中的图标名称，也可以是绝对路径。 |
| `size` | 支持 `1x1`、`2x2`、`4x2` 或 `4x4`。 |
| `col`, `row` | 可选：将磁贴固定到当前分组内的指定网格位置。 |
| 分组 `title` | 显示在分组上方的标题；默认为空。 |

磁贴在分组内按从左到右、从上到下的顺序排列，当内容增多时磁贴区域支持向下滚动。布局文件本身不记录菜单显示的列数——具体列数由当前屏幕宽度决定，因此当菜单在不同宽度的显示器上打开时，各分组会自动重新流式排布以适配屏幕。旧版采用扁平 `groups` 列表的布局文件会在加载时自动迁移并保留原有排布。如果不存在布局文件，菜单启动时将仅显示应用列表；当你首次将应用固定到开始屏幕时，系统会自动创建该文件。

<details>
<summary>技术说明</summary>

* **设计基准比例。** 菜单界面基于 2560×1440 分辨率桌面在 150% 缩放下的设计像素编写（即 1 个设计像素等于 2/3 个设备独立像素），再由 Qt 结合设备像素比映射输出到显示器。在 150% 缩放下，渲染效果与设计参考基准完全一致。
* **渲染测试框架。** `MetroMenu` 接收单一的 `context` 上下文对象，这使得外部渲染工具可以直接复用小组件自身的绘制代码，同时注入自定义的应用程序列表、布局、图标、壁纸与头像数据进行独立渲染。
* **壁纸与侧边栏渲染。** 菜单自行绘制并调暗当前桌面壁纸，左侧边栏也在应用内部对其后方内容进行实时模糊处理。整个过程不依赖任何窗口合成器特效，因此不会影响其他窗口，且在关闭合成器模糊特效时依然保持完全一致的视觉效果。
* **头像着色器。** 头像的圆形裁剪通过片元着色器实现；修改 `circle.frag` 后，需使用 Qt Shader Tools 重新编译生成：`qsb --qt6 -o circle.frag.qsb circle.frag`。
* **自动化测试。** 运行 `node tests/persistence.test.js` 可在临时目录中调用真实的库文件与 Shell 命令，对首次运行固定磁贴、各类布局文件状态以及保存指令进行完整测试。

</details>
